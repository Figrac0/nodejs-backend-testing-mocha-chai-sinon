# Node.js + TypeScript Todo API

A simple REST API built with **Node.js**, **Express**, and **TypeScript** to demonstrate basic backend development practices such as routing, request validation, and CRUD operations.

## Features

- Node.js backend using Express
- Fully written in TypeScript
- Simple in-memory data storage
- RESTful API structure
- Basic input validation
- Proper HTTP status codes
- Typed request and response handling

## Tech Stack

- Node.js
- Express
- TypeScript

## Purpose

This project demonstrates:

- how to structure a **Node.js + Express + TypeScript** backend
- how to build simple **REST APIs**
- how to use **TypeScript types with Express**
- how to implement **basic CRUD logic**

The data is stored in memory, so it resets when the server restarts.
